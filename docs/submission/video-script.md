## บทพูด

**1. ปก (0:00–0:15)**
สวัสดีครับ ผมกฤตนัย กัปตพล ขอนำเสนอโครงงาน Plimo iPhone Repair แชทบอทผู้ช่วยร้านซ่อม iPhone ที่ใช้ LLM เป็นแกนหลัก ทั้งตอบลูกค้าและช่วยงานแอดมิน ระบบนี้ใช้งานได้จริงบนเว็บที่เห็นอยู่ครับ

**2. ธุรกิจ (0:15–0:40)**
ธุรกิจคือร้านซ่อม iPhone รับเฉพาะ iPhone 11 ถึง 17 รวม Pro และ Pro Max เปิดทุกวันสิบโมงถึงสองทุ่ม ปิดวันพุธ ตรวจเช็คฟรี จุดเด่นคือความโปร่งใส แจ้งราคาประเมินก่อน แล้วส่งใบเสนอให้ลูกค้าอนุมัติก่อนซ่อมทุกครั้ง กลุ่มเป้าหมายคือคนที่อยากรู้ราคาก่อนเดินทางมา และอยากติดตามงานซ่อมเองออนไลน์ ปัญหาของร้านคือต้องตอบคำถามซ้ำทั้งวัน และติดตามหลายเคสพร้อมกัน

**3. แนวคิด (0:40–1:00)**
แนวคิดคือให้ LLM เป็นแกนกลาง ทำสองหน้าที่ หน้าที่แรกตอบลูกค้า ตั้งแต่ราคา อาการเสีย อ่านรูป ไปจนเปิดเคส อนุมัติราคา และจ่ายเงิน หน้าที่ที่สองช่วยแอดมิน สรุปเคสและเสนอราคาจากแค็ตตาล็อก หลักสำคัญคือ "AI เสนอ ระบบยืนยัน" ตัวเลขราคา สถานะเคส และการชำระเงิน มาจากฐานข้อมูลเสมอ โมเดลแต่งเองไม่ได้

**4. สถาปัตยกรรม (1:00–1:25)**
หน้าเว็บผ่าน Caddy ที่ทำ HTTPS และ nginx ที่จำกัดจำนวนคำขอ ข้อความทุกข้อความเข้า FastAPI ผ่าน 7 ขั้น คือตัวกรอง ตรวจรูป เช็ค cache ให้ router จัดเจตนา ถ้าเป็นเรื่องเคสก็ตอบจากฐานข้อมูลตรงๆ ถ้าเป็นคำถามร้านก็ค้นคลังความรู้ด้วย LightRAG แล้วให้ gpt-5.4-mini ตอบ ก่อนส่งกลับมีตัวตรวจคำตอบ ข้อมูลอยู่ใน Redis และ SQLite จ่ายเงินผ่าน Stripe และเก็บรูปใน Cloudflare R2 แบบส่วนตัว

**5. Guardrails (1:25–1:50)**
จุดเด่นแรกคือ guardrails แปดชั้น ถ้าชั้นหนึ่งพลาด ยังมีชั้นถัดไปกันอยู่ nginx จำกัดจำนวนข้อความ ตัวกรองซ่อนเลขบัตรด้วย Luhn และจับคำสั่งโจมตีก่อนถึงโมเดล รูปผ่าน moderation และจัดประเภท router ส่งคำถามนอกเรื่องไปที่ข้อความคงที่ ที่สำคัญคือชั้นที่หก ตัวตรวจคำตอบ ตัวเลขราคาทุกตัวต้องมีในแค็ตตาล็อก และชั้นที่เจ็ด AI ทำรายการเองไม่ได้ ลูกค้าต้องพิมพ์ยืนยันก่อน ทั้งหมดจับคู่กับ OWASP ครบทุกหมวด

**6. RAG + Router (1:50–2:15)**
จุดเด่นที่สองคือ RAG ที่วัดผลได้ ผมสร้างชุดวัดการค้น 40 คำถาม รอบแรกเอกสารที่ถูกต้องขึ้นอันดับหนึ่งแค่ 31 เปอร์เซ็นต์ หลังแยกคลังเป็น 53 หัวข้อและจูน ตอนนี้เอกสารที่ถูกต้องอยู่ใน 3 อันดับแรก 98 เปอร์เซ็นต์ ส่วน router เข้าใจบทสนทนา เช่นพิมพ์ว่า "แล้ว 14 ล่ะ" ระบบจะเขียนใหม่เป็นคำถามเต็มก่อนค้น ต้นทุนประมาณ 0.0028 ดอลลาร์ต่อคำตอบใหม่ คำถามซ้ำแทบไม่เสียเงิน

**8. ผลทดสอบ (3:35–3:50)**
ผลทดสอบทั้งหมดรันอัตโนมัติบนเว็บจริง คำถามทดสอบ 143 ข้อผ่านครบ API ทุก endpoint ทำงาน RAG ค้นเจอเอกสารที่ถูกต้องใน 3 อันดับแรก 98 เปอร์เซ็นต์ สุ่มกติกาต้องทำห้ามทำผ่าน 33 ข้อ ตรวจความปลอดภัยผ่าน 51 รายการ และวงจรเคสด้วย AI ผ่านครบ 16 ขั้น ผลทุกข้ออยู่ใน GitHub

**9. ปิด (3:50–4:00)**
